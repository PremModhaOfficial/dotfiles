## 1. Evidence for the three layout claims, before and after

### Claim A — "live paths are symlinks into dotfiles" (was memory-harness-home.md:20-21)

**Before** — the file said: `dotfiles — git repo, source of truth (stow-style: live paths
are symlinks into it)`. Measured, that is false for the bin scripts the same updater
writes:

```
$ ls -l ~/.config/herdr/bin/herdr-theme
-rwxr-xr-x 1 prm prm 4391 Oct 16 17:52 /home/prm/.config/herdr/bin/herdr-theme
$ stat -c 'live=%i dotfiles-inode=%s links=%h' → live inode=1636780 dotfiles inode=2925354 links=1
$ cmp -s ~/.config/herdr/bin/herdr-theme ~/dotfiles/herdr/bin/herdr-theme && echo SAME
SAME
$ grep -n 'herdr/bin/herdr-theme' ~/dotfiles/jcode/update-all.sh
683:  if [ -f "$DOTFILES/herdr/bin/herdr-theme" ]; then
685:    install_if_different "$DOTFILES/herdr/bin/herdr-theme" "$HOME/.config/herdr/bin/herdr-theme"
```

Different inodes, one link, same bytes → a **copy**. `SAME` today only because the updater
ran; it was `DIFF` in the round-2 run. Editing the dotfiles file does not change the
user's command until `install_if_different` copies again.

**After** — a per-path table names kind and reason: `/home/prm/.agents` link,
`~/.config/herdr/config.toml` link, `bin/herdr-theme` + `themes/*.toml` copies
(`update-all.sh:683-692`), `~/.jcode/{bin,themes,hooks}` copies (`:663-680`),
`~/.a5c/processes` copy (`cp -R`), `~/.pi/agent/AGENTS.md` generated,
`~/.pi/agent/skills/<name>` one symlink per entry (34/34),
`~/.commandcode/skills/<name>` mixed (83 links, 117 real dirs). Plus a live trap I found
while measuring: `~/.jcode/config.toml` is a copy the updater **preserves** when it
differs, and it differs right now (`cmp` → DIFF; the live file has `[cloud]`/`[session]`
keys the repo lacks), so a dotfiles edit there can never be claimed as live. Verified:
`ls -l`, `stat`, `cmp`, `ls -ld ~/.config/herdr/plugins` and `diff -rq` of it.

(`cut -f1 ~/.jcode/state/upstream-sources | grep -qx <skill>`), and states the rule:
sync-owned ⇒ overlay; otherwise the dotfiles file **is** the running file, so edit it
there and commit. No list of 34 names to rot.

### Claim C — "`~/.config/fish` is a one-hop dotfiles link" (defect 5 / D8)

**Before** — one hop implied, and this ticket's own text says "two hops".

