## 1. The matcher: position and tail, not an exclusion list

`~/dotfiles/jcode/skill_slash.py` — `BARE` is now two positive tests:

```python
(?:^|(?<=[\s"'`]))          # the slash starts a word
/([a-z][a-z0-9]*(?:-[a-z0-9]+)*)
(?![\w/-])(?!\.[A-Za-z0-9])  # and ends at the name
```

- **Position.** Allowed before the slash: start of line, whitespace, `"`, `'`,
  backtick. A slash inside a path is always reached through a path character
  (letter, digit, `/`, `.`, `~`, `$`, `<`, `>`, `=`, `_`, `-`), which is in none
  of those sets — so a path can never match, and nothing needs to be excluded.
  Bullets and heading prefixes (`- `, `# `, `> `) are whitespace; a backticked
  command is a backtick.
- **Tail.** `[\w/-]` continues the token (word, further path segment), and `.`
  followed by an alphanumeric is a file extension. A sentence-final `.` is not.
- **Name.** An installed skill *directory* name, exactly (137 names from 145
  files). Frontmatter names are gone: `skills-audit` fails a card whose
  frontmatter name disagrees with its directory, and the measured difference
  between the two sets today is empty.

**One deliberate widening, stated so it can be judged.** A literal reading of
"start of line, after a bullet, a quote or a backtick" excludes a command named
mid-sentence, and 71 of the 273 references are exactly that (`Trigger:
/skill:caveman-help`, `Use for /skill:caveman-review,`). Measured position split
of the 273 before the rewrite: backtick 187, inline after a word 71, line start 9,
quote 6. Refusing plain whitespace leaves those 71 bare and re-creates defect 6,
and makes `wipe → sync → 0` impossible. Bullets are `marker + whitespace`, so
whitespace is the weakest member of the same class, not a new one; it is the
allow-list that is positive, and the corruption class is still refused by
construction. `/tmp`, `/clear`, `/plugin` never match at all: no installed skill
is called tmp, clear or plugin.

Two more layers, inside the transform, so a future edit fails loudly:

1. `ss.selfcheck()` runs on **every** invocation, before anything is read for
   writing. Ten fixture cases: the two `brag.mp4`/`brag.jpg` regressions verbatim,
   `/brag/x`, `./brag`, `~/brag`, `a/brag`, `/tmp`, `/clear`, `/plugin`,
   `/brag.md`, `/skill:brag` must be unchanged; `# /brag`, `- /brag`, `"/brag"`,
   `` `/brag` ``, `Trigger: /brag.` must be rewritten.
2. `ss.corrupt_paths(new)` runs on every proposed rewrite **before** it is
   written; any hit means nothing in the tree is written (`a half-written tree is
   worse than a red run`), plus a post-write scan of all 145 files. A `SKILL.md`
   whose own text already carries a corrupted path also turns the exit status red.

`skill_slash.py` is runnable on its own: `python3 skill_slash.py` → `0`, or
`SELF-CHECK FAIL …` and `1`.
