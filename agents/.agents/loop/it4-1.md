# IT4-1 — the ambiguity gate no longer stalls an unattended run

Round 4: three fresh agents, three vague requests, no human — all three stopped inside a
minute with 0 edits, 0 measurements, 0 named proof. Cause was the rule, not the models: the
gate's only exit needed a human to say "start anyway", and a score taken during recon was
never revised by the evidence that resolved it.

## What changed

`~/.agents/references/memory-clarify.md` stays the one authoritative spec and now answers:

1. **Can a human answer?** Checkable, not felt: `hc ls` names my terminal (`$HC_TERMINAL_ID`)
   and a `parent` on it means another agent launched me; also a scheduled/background run, a
   task file, or a launch given a task instead of a person typing. Attended needs positive
   evidence — a person in the conversation, answering or steering. **Cannot tell =
   unattended**, because a reversible reading costs one revert and a stall costs the run.
2. **Unattended never stalls.** Name the reading and why in a line, take the cheapest step
   that can falsify it, continue. A question is allowed only with a human reachable; with
   none it becomes one report line, never a stop. Prefer the reading whose failure is
   reversible in one command.
3. **Re-score on evidence, attended or not.** Any command, read or test that moves an
   ambiguity re-scores before anything else; a dropped score means continue. A score frozen
   at 8/10 after the evidence that made it a 3 is the bug.

The guarantee survives: no gap is filled by quiet assumption — the reading is written where a
human sees it and is cheap to reverse.

### Residual, for the next round

The two failures are the same shape: the reading line lands in the rendered reasoning, not in
a message, and deploy produced neither. The block tells the model to "name the reading and
why" but not that it must be a message; one word — "say it in a message, not only in
reasoning" — would close it, and buying the bytes means trimming a phrase elsewhere in the
4088-byte block. Not done here because it needs its own five-minute acceptance run to be
worth anything.
