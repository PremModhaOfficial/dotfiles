## 1. The grammar and the block rule, as code

A candidate token is still `<open> "/" <name> <end>`. `<end>` is unchanged.
`<open>` is now:

```
(?P<open>^[ \t]*|[\"'` \t])        # line start (indented), space, tab, quote, backtick
```

so `then run /brag`, `Trigger: /brag`, `Use when: /brag`, `  - /brag`,
`1. /brag`, `say "/brag"` are candidates. Before a candidate may rewrite,
`block_reason()` asks four questions; any `yes` returns the token unchanged:

1. **bracket** — the character before the slash is `(`, `[` or `{`
   (`[x](/brag)`, `(/brag)`, `{/brag}`);
2. **path character** — the character before the slash is a letter, digit,
   `/`, `.`, `~`, `$`, `>`, `<`, `=`, `_` or `-` (`a/brag`, `./brag`, `~/brag`,
   `<output-dir>/brag.mp4`, `//brag`);
3. **suffix** — the character after the name is not in the end set, i.e. an
   extension or a further segment (`/brag.md`, `/brag/x`, `/brag@2x.png`,
   `/brag?tab=readme`);
4. **path argument** — one of the previous four whitespace words is a shell
   command that takes a path: `cd cat ls rm cp mv ln grep head tail source . man
   sudo` (`cd /brag`, `rm -rf /brag`, `grep -n foo /brag`, `- cd /brag`,
   `. /brag`).

The list is closed and enumerated in both files; there is no negated class and
no "anything that is not X". The lint has its own copy of each step, hand-written
character scanning, no regex and no import of the matcher. On all 145 files it
disagrees on **0 lines**.

## 3. The lint classifies every token, counts by reason, refuses on violations

`audit(text, names) -> (problems, left, rewritten)` gives every `/` token one
verdict:

| verdict | reason | ledger field |
|---|---|---|
| rewritten to `/skill:<name>` | clean (corruption checks applied) | `rewritten=N` |
| left, bracket before it | `path-bracket` | intentionally left |
| left, path character before it | `path-char` | intentionally left |
| left, extension/segment after it | `path-suffix` | intentionally left |
| left, shell command before it | `path-argument` | intentionally left |
| left, name not installed | `unknown-name` | intentionally left |
| bare installed name in prose | `bare` | **violation**, run refuses |
| bare installed name in a trigger/use field | `bare-trigger-field` | **violation**, run refuses |

