# prem-search

The vocabulary of a research skill that chooses its own method before it searches. A search here is not "go look things up": it is a **Method** selected from three axes that change every run, then executed. The words below are fixed so the skill thinks in the same terms every time.

## Language

**prem-search**:
Research that recons first. Before any searching, it establishes how to research this **Topic** at this **Time** on this **Harness**, then runs that **Method**.
_Avoid_: search, deep research, investigate, look up

**Recon**:
The bounded, pre-search phase that produces the **Method**. It probes the three axes and stops.
_Avoid_: planning, meta-research, strategy, scoping

**Method**:
The chosen way to research this **Topic** at this **Time** on this **Harness**: which sources to trust, which tools to use, and in what order.
_Avoid_: plan, approach, methodology, strategy

**Topic**:
What is being researched. Owns the question, not the answer.
_Avoid_: subject, query, subject matter, problem

**Time**:
The state of the world, and of the art of research, at the moment the search runs. Methods go stale; the **Method** must fit today, not a remembered default.
_Avoid_: now, date, today, recency, present

**Harness**:
The agent runtime executing the search and the real capabilities it exposes (web search, browser, MCP servers, subagents, background tasks). A **Method** that assumes a capability the **Harness** lacks is wasted.
_Avoid_: runtime, platform, environment, agent, machine

**Finding**:
A claim verified against the **Primary source** that owns it, recorded with that source.
_Avoid_: result, takeaway, insight, data point

**Primary source**:
The source that owns a claim: an official spec, first-party docs, source code, a standards body, the paper itself. Never a write-up of one.
_Avoid_: secondary source, article, blog, summary
