# T3 preview

- After two failures on one step, quote the error and switch to another installed browser: Chrome, Chromium, Edge, Brave, Safari, or Firefox. If the second browser fails, report and stop.
- `html_preview` then `html_render` for charts and requested visuals. For a file, pass its HTML. Never start a server to show a visual.
